ROBO-DOC Chatbot

A Healthcare Chatbot that predicts possible diseases based on patient symptoms using ML classification, returning disease descriptions and precautions through an interactive chat interface.

NLP TF-IDF Flask Scikit-learn Healthcare

Overview

ROBO-DOC maps patient-described symptoms to a trained ML classifier using TF-IDF vectorisation for text preprocessing. Beyond prediction, it returns structured disease information including descriptions and recommended precautions. The full research and model development process is documented in ROBO_DOC.ipynb — covering data exploration, feature engineering, model experimentation, and final conclusions.

Key Features

  • Symptom-based disease prediction using ML classification
  • TF-IDF text preprocessing and NLP feature extraction
  • Returns disease name, description, and precautions per prediction
  • Multi-turn interactive chatbot interface
  • ROBO_DOC.ipynb documenting the full research and model workflow
  • Experiments folder with NLP, feature extraction, and model comparison notebooks
  • Clean Flask backend with HTML/CSS frontend

Technical Challenges

Medical NLP requires careful handling of ambiguity in symptom descriptions. Mapping free-text input to structured symptom features required a robust preprocessing pipeline and a curated vocabulary of medical terms to ensure consistent model inputs.
