Expense Tracker

A full-stack personal finance application with real-time expense logging, budget management, category breakdowns, and trend visualisations to support smarter financial decision-making.

Full-Stack React MongoDB Node.js Data Viz

Overview

Expense Tracker is a responsive web app that lets users log income and expenses, set monthly budgets per category, and visualise their spending trends over time. The backend is a RESTful Node.js/Express API with JWT authentication; data is stored in MongoDB. The React frontend uses Chart.js for interactive dashboards and Tailwind CSS for styling.

Key Features

  • Expense and income logging with category, date, and note fields
  • Monthly budget targets per category with over-budget alerts
  • Interactive doughnut and line charts for spending visualisation
  • CSV export of transaction history for any date range
  • Recurring transaction support with configurable frequency
  • Secure JWT-based authentication with refresh token rotation

Technical Challenges

Ensuring data consistency when users edit or delete recurring transactions required a carefully designed cascade logic. The budget alert system needed real-time recalculation on every new transaction, handled via server-sent events to update the dashboard without a full page reload.
